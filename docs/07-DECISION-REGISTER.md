# Decision Register

Compact canonical summary for agents and future design work.

## LOCKED

* The game is developed independently from the Avrana Party device/appliance.
* The game is phone-native and uses private player screens.
* The server owns authoritative game state.
* The cooperative ship layer must be fun without betrayal.
* In-person players may always speak aloud.
* Remote/Text mode is separate from In-person mode.
* Mission is public, fixed, and Scenario-defined.
* Primary Objective is a participant's personal victory condition.
* Mission and Primary are usually identical at game start but are different concepts.
* Primary Objectives may occasionally diverge at setup.
* Primary Objectives may change through explicit player choice.
* Manipulation does not automatically change a player's objective.
* Human traitors are not guaranteed.
* AI motive and AI integrity are separate.
* Authentication proves sender identity, not truth.
* Deception must have counterplay.
* Uncertainty must be investigable.
* Victory and score are separate.
* A losing player may outscore a winner.
* Standard Scenario is the MVP scenario.
* Advanced scenarios do not block MVP.
* The AI does not require a runtime generative model for the design to work.

## PROVISIONAL

* Synchronous round structure.
* Simultaneous action commitment.
* Approximately 2 actions per player per round.
* Approximately 8–10 rounds.
* 15–20 minute early prototype.
* 4-player first prototype.
* 4–6 core ship systems.
* 3–5 shared resources.
* Soft crew specialties.
* AI can request and receive subsystem authority.
* Objective/deal history ledger.
* Limited independent audit subsystem.
* Player-to-player recruitment.
* False acceptance/rejection as an advanced mechanic.
* Escape pods as a later mechanic.

## FUTURE

* Emissary Scenario.
* Cargo Scenario.
* Quarantine Scenario.
* AI Core Scenario.
* Rescue Scenario.
* Deep Remote/Text communication warfare.
* Post-death roles.

## Design litmus tests

Before adding a mechanic, ask:

1. Does it create a meaningful choice?
2. Can a new player understand the immediate consequence?
3. Does it support the core ship/information/motive game?
4. Can players reason about it rather than simply suffer it?
5. Is this necessary now, or is it future scope wearing a fake mustache?
